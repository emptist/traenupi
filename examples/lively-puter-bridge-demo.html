🎭 Lively4 Integration

📍 Where Lively4 Appears

  • Adapters: src/common/lively-puter/adapters/lively/
  • Features: Local file system, real-time collaboration
  • Hybrid Mode: Used for /tmp, /cache, /local paths
  • Requires: Lively4 runtime environment
// Lively4 适配器 export class LivelyFileSystemAdapter { async write(path, content) { // 使用 Lively4 的文件系统 const files = await lively.import('src/client/files.js'); await files.write(path, content); } }

🔀 Hybrid Routing Strategy

How the Bridge Routes Requests

  • /tmp, /cache, /local → Lively4 (fast local access)
  • /documents, /projects → Puter (cloud sync)
  • cache:, temp:, session: → Local database
  • user:, settings:, data: → Cloud database
// 智能路由示例 await bridge.fs.write('/tmp/cache.json', data); // → Lively4 await bridge.fs.write('/documents/report.txt', text); // → Puter await bridge.db.set('cache:session', session); // → Local await bridge.db.set('user:preferences', prefs); // → Cloud

💻 Real Integration Examples

Using in TraeNuPI TypeScript

// In any TraeNuPI module import { LivelyPuterBridge } from './common/lively-puter/index.js'; export class MyTraeNuPIModule { private bridge: LivelyPuterBridge; async initialize() { this.bridge = new LivelyPuterBridge(); await this.bridge.initialize(); } async saveData(data: any) { // Automatically uses hybrid routing await this.bridge.db.set('data:my-module', data); } }

Using in Gleam

// In Gleam code import traenupi_core/lively_puter as bridge pub fn save_data(data: String) { let config = bridge.default_config() let assert Ok(_) = bridge.initialize(config) let json_data = json.string(data) bridge.db_set("data:my-module", json_data) }
